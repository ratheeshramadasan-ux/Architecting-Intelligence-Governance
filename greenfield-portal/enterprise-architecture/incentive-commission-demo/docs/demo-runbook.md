# Demonstration runbook

1. Open Dashboard and establish the synthetic environment, active control posture, and current trace.
2. In Processing, run SCN-01 to show tokenized identity, multi-section retrieval, deterministic calculation, and sealed evidence.
3. Run SCN-04 to show a duplicate preserving the calculation while blocking payment and routing a process-owner case.
4. Run SCN-06 to show compliance precedence and human review.
5. In SOP / RAG, open v3 to show the intentional fake SIN finding and blocked lifecycle. Contrast it with approved v2.
6. In Governance, show `ADC-INC-04 v3`: financial values are allowed because calculation needs them, names are tokenized, and unknown fields are blocked.
7. In Exceptions, show the model/calculation variance. Explain that the deterministic result wins and payment stays blocked.
8. In Approvals and Security, demonstrate that an operations analyst lacks approval permission and the same user cannot submit and approve.
9. In Audit evidence, inspect the immutable trace fields and evidence hash.

The ten canonical inputs and expected outcomes are in `data/golden/acceptance-scenarios.json`.
