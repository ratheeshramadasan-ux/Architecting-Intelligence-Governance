# Visual Component Catalogue

Implemented foundation components:

1. Visual Story Hero — ecosystem, transformation, and controlled-outcome openings.
2. Transformation Journey — 14-stage responsive lifecycle.
3. Role Explorer — responsibility-led entry paths.
4. Outcome Metrics Strip — border-led measures without generic cards.
5. Architecture / Process Flow — selectable, data-driven nodes with text alternatives.
6. Governance Wheel — integrated governance domains around business value.
7. Governance Operating Model — decision-right progression.
8. Control-Layer Explorer — policy through audit.
9. Risk Escalation Journey — detection through learning.
10. RACI Swimlane — visual hand-offs with authoritative table link.
11. Agent Execution Journey — playable, pausable, reduced-motion-safe sequence.
12. MCP Ecosystem Explorer — governed enterprise tool access.
13. Agentic Control Plane — runtime control domains.
14. Human Approval Pause — proposal, accountable decision, audit record.
15. Progressive Explanation — executive through implementation perspectives.
16. Readiness Flow — evidence to outcome.
17. Intelligent Search Entry — business-question-first discovery.

All components use structured arrays/configuration, semantic elements, responsive layouts, keyboard actions, static fallbacks, and shared tokens. Future variants should extend configurations rather than fork markup.
