# Page Template Catalogue

All templates follow: visual opening → business context → interactive explanation → architecture/process → outcomes and risks → theory → tools → related content.

| Template | Primary components | Deep content placement |
|---|---|---|
| Executive Overview | Story hero, value model, metrics, decision canvas | Evidence and assumptions below decisions |
| Transformation Journey | Journey, milestones, dependencies, roadmap | Stage theory after journey |
| Methodology Stage | Stage hero, workflow, owners, outputs | Detailed workstreams and evidence below |
| Architecture Explainer | Ecosystem, layers, boundaries, overlays | Specifications and failure modes below |
| Technology Explainer | Concept-in-60-seconds, process, comparison | Implementation details below |
| Governance Framework | Wheel, operating model, controls, RACI | Regulation and policy theory below |
| Assessment | Maturity journey, dashboard, heat map | Questions and scoring logic below |
| Decision Guide | Decision tree, matrix, canvas | Criteria and exceptions below |
| Comparison | Before/after, shared dimensions | Detailed comparison table below |
| Implementation Guide | Roadmap, process, controls | Step instructions below |
| Business Use Case | Scenario, intervention, controls, outcomes | Technical design below |
| Process Journey | Flow, swimlane, workflow explorer | SOP and exception detail below |
| Reference Architecture | Layers, ecosystem, boundaries | Component specification below |
| Template / Accelerator | Outcome, preview, usage journey | Download and instructions below |
| Knowledge Article | 60-second concept, progressive views, glossary | Full theory and references below |

Mobile uses stacked narrative sections and horizontally scrollable relationship diagrams. Motion is optional; focus order follows the visual reading order.
