# Recommendation for Portal-Wide Migration

Recommendation: proceed only after visual approval of the three pilots.

## Proposed sequence

1. Approve tokens, icon vocabulary, motion restraint, and narrative sequence.
2. Resolve pilot feedback in the shared component layer.
3. Migrate high-traffic executive and methodology pages.
4. Migrate architecture, governance, assessment, and decision pages by template family.
5. Migrate knowledge articles and accelerators.
6. Complete full regression, accessibility, performance, and route validation.

## Migration rules

- Preserve canonical content and route ownership.
- Add a structured visual model before editing prose.
- Reuse components; do not create page-specific visual dialects.
- Keep authoritative tables and downloadable artifacts beneath visual explanations.
- Measure success by comprehension, task completion, accessibility, and evidence traceability—not visual novelty.

## Gate criteria

Approve portal-wide migration only when reviewers can understand each pilot’s main concept within 30 seconds, follow its business story without reading the long-form theory, operate every interaction by keyboard, and recognise one consistent enterprise language.
