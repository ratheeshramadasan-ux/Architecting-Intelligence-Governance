# Enterprise Visual Design Language

## Intent

The visual language combines enterprise-consulting clarity with architecture storytelling. The first viewport communicates one business message; deeper layers progressively introduce process, controls, technical architecture, risks, and theory.

## Foundations

| Element | Standard |
|---|---|
| Primary identity | Deep navy and established teal |
| Decision accent | Restrained gold |
| Risk / success | Muted red / enterprise green |
| Type | Existing portal typography; large, compact executive headings |
| Layout | 1180 px content frame, strong whitespace, bounded reading measure |
| Shape | Mostly square/soft rectangular; circles only for ecosystems and control centres |
| Depth | Borders and whitespace first; shadows reserved for focal concepts |
| Imagery | Purposeful diagrams and icons; no stock imagery or decorative illustration |

## Story sequence

Visual explanation → business context → interactive journey → architecture/process visual → outcomes and risks → detailed guidance → tools → related content.

## Responsive rules

Wide diagrams scroll horizontally when their relationships would be damaged by stacking. Grids reduce from four columns to two and then one. Orbit diagrams simplify without removing labels. Touch targets remain at least 44 px where practical.
