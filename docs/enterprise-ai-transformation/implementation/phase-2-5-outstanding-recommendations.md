# Outstanding Recommendations Before Phase 3

## Enterprise configuration

- Confirm named assessment owners and evidence custodians.
- Agree minimum evidence thresholds for category roll-up.
- Approve weighting only where a defensible enterprise decision requires it.
- Define assessment review and expiry cadences.
- Select systems of record for findings, risks, actions and approvals.

## Phase 3 integration

- Use Enterprise AI Readiness as the Phase 3 anchor assessment.
- Map verified Discover evidence into assessment questions without copying source records.
- Define readiness decision thresholds and conditional approval rules.
- Populate dashboards only from approved assessment results.
- Trace improvement actions into strategy, governance, architecture and business-case work.

## Deferred by design

- Live AI execution, pending model, privacy, security and governance approval.
- Persistent assessment responses and workflow logic, because this phase requested reusable platform structure rather than implementation logic.
- Production deployment, which remains explicitly prohibited.
