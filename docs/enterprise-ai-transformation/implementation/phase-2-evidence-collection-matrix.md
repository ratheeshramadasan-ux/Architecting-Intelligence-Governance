# Phase 2 — Evidence Collection Matrix

The canonical machine-readable matrix is [discover-evidence-matrix.json](../../../greenfield-portal/assets/data/discover-evidence-matrix.json).

It contains 164 evidence requirements across all 20 discovery domains. Each row records:

- identifier and domain;
- information required and decision purpose;
- expected source and system of record;
- business owner and technical owner;
- validation method and evidence type;
- initial confidence classification and refresh frequency;
- deliverables that consume the evidence.

Initial confidence describes the reliability expectation for the requirement definition, not the confidence of enterprise evidence that has not yet been collected. Evidence status must be updated only after source verification.
