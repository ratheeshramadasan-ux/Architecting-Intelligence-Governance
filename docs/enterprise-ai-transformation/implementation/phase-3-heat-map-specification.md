# Phase 3 — Heat Map Specification

Seven reusable visualisations are provided:

1. Capability Heat Map
2. Risk Heat Map
3. Readiness Heat Map
4. Business Impact Matrix
5. Effort vs Value Matrix
6. Dependency Matrix
7. Roadmap Timeline

Every visualisation must:

- use verified inputs and show evidence confidence;
- define thresholds and colour meaning explicitly;
- preserve accountable ownership and record identifiers;
- provide an equivalent table or narrative;
- avoid presenting placeholder values as enterprise results;
- remain understandable without colour alone.

The portal demonstrations intentionally show “No data” until approved results exist.
