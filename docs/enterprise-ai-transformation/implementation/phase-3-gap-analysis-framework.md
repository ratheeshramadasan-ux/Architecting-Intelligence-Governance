# Phase 3 — Gap Analysis Framework

## Required fields

- Current State
- Target State
- Business Impact
- Risk
- Priority
- Estimated Effort
- Dependencies
- Owner
- Target Resolution Stage
- Related Capability
- Related Deliverables
- Recommendation

## Lifecycle

Identified → Validated → Approved → In progress → Blocked or Resolved → Accepted

## Rules

- Every gap requires traceable evidence and assessment context.
- Priority cannot override a critical regulatory or safety constraint.
- Effort remains a range until delivery planning validates it.
- Closure requires new evidence and accountable approval.
- Maturity, readiness and evidence confidence remain separate.
- Averages must not hide critical control failures.
