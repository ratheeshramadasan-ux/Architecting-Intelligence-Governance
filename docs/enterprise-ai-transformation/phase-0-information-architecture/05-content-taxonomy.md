## Required metadata

Stable ID, canonical title, slug, summary, stage, workstream, page type, audiences, owner, reviewer, status, version, last/next review, prerequisites, outputs, related deliverables, related controls, related architecture, sources and canonical URL.

Machine-readable values are defined in [taxonomy.json](data/taxonomy.json).
