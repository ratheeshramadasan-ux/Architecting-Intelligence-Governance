# 0.8 Naming and terminology register

The detailed register is [naming-register.csv](data/naming-register.csv).

## Editorial rules

- Prefer plain-language lifecycle verbs.
- Expand an acronym on first use and link its canonical glossary entry.
- Use one canonical name for each concept.
- Distinguish governance requirements from implementation mechanisms.
- Use Canadian/British spelling consistently, subject to Platform Owner approval.
- Avoid vague titles such as “Solutions” and “Framework Overview”.

Canonical corrections include `AI and Automation Opportunity Prioritisation`, `Enterprise AI Control-Plane Architecture`, `Intelligent Document Processing Pattern`, `Third-Party AI Assurance`, and `Deliverable and Template Catalogue`.
