# 0.6 Duplicate and overlap register

The full register is available as [duplicate-overlap-register.csv](data/duplicate-overlap-register.csv).

Key findings:

- Governance is distributed across AI Governance, Governance Integration, Greenfield Implementation and Assurance.
- Security review content overlaps Data Security, AI Architecture and Assurance.
- The architecture landing page duplicates summaries from AI Architecture and Infrastructure Architecture.
- Solutions, prioritisation and automation-spectrum pages mix opportunity discovery, taxonomy and selection.
- Resources presents files rather than governed deliverables.

No content should be deleted automatically. Each merge requires paragraph-level comparison, source preservation and redirect approval.
