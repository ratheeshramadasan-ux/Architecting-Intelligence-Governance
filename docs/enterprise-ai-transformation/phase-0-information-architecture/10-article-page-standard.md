# 0.10 Standard article-page specification

## Required page order

1. Canonical title and one-line definition
2. Executive summary
3. Plain-language explanation
4. When this guidance applies and does not apply
5. Business problem and value
6. Inputs, prerequisites and dependencies
7. Practical method or implementation steps
8. Architecture, governance and security implications
9. Roles and decision rights
10. Deliverables and evidence produced
11. Operations, monitoring and failure handling
12. Risks, anti-patterns and misconceptions
13. Decision criteria
14. Related lifecycle pages, concepts, controls and tools
15. Sources, evidence class, version and review date

## Content rule

Lifecycle articles explain context and action. Canonical Knowledge Centre articles define reusable concepts. Content is referenced across stages rather than copied. Incomplete implementation material is labelled `planned` or `partial`.
