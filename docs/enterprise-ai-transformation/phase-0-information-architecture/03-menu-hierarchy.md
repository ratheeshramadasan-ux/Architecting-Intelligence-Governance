## Lifecycle stage menus

Every stage contains:

1. Stage Overview
2. Stage-specific workstreams
3. Stage Deliverables
4. Stage Templates
5. Stage RACI
6. Stage Approval Gate
7. Stage Exit Checklist

Stage workstreams:

- **0 Mobilise:** mandate, business drivers, charter, scope, objectives, sponsorship, stakeholders, programme governance, decision rights, delivery model, funding, risk appetite, principles, success measures and RAID.
- **1 Discover:** business, process, customer, applications, integrations, technology, infrastructure, cloud/compute, AI/automation platforms, data, security, identity, privacy/legal, compliance, vendors, workforce, governance, risks, cost, current use cases and shadow AI.
- **2 Assess Readiness:** business, leadership, operating model, governance, technology, architecture, infrastructure, data, security, identity, privacy/legal, delivery, workforce, change, finance, vendor and operations readiness; scoring, maturity, gaps and remediation.
- **3 Define Strategy:** vision, outcomes, principles, ambition, capabilities, operating/delivery/sourcing models, platform/data/security/workforce/change/vendor/investment strategies, benefits and roadmaps.
- **4 Establish Governance:** operating model, principles, policies, responsible AI, risk classification, model/agent/data/privacy/security/identity controls, oversight, explainability, fairness, transparency, evidence, compliance, legal, vendor/IP, incidents, exceptions, assurance, metrics, forums and rights.
- **5 Prioritise Opportunities:** discovery, problem definition, capability/process/customer/employee/automation/document/analytics/generative/copilot/agent opportunities, intake, feasibility, data, security/privacy, risk, value, cost, complexity, dependencies, prioritisation, balancing, pilot selection and roadmap.
- **6 Build Business Case:** baseline, benefits, implementation/platform/model/infrastructure/data/security/operations/change costs, TCO, ROI, benefits realisation and funding.
- **7 Design Target Architecture:** principles; business, information, data, application, integration, AI/model/RAG/agent/automation/security/identity/infrastructure/cloud/hybrid/network architectures; gateway, routing, vectors, knowledge, MCP/tools, guardrails, observability, resilience, retention, ADRs and reference architectures.
- **8 Plan Implementation:** delivery approach, work breakdown, releases, environments, data, integration, security, identity, models, evaluation, testing, change, training, communications, support, cutover, rollback, RAID and governance.
- **9 Build and Integrate:** environments, data pipelines, integrations, prompts, retrieval, agents, automation, controls, identity, telemetry, documentation, configuration and build evidence.
- **10 Test and Validate:** functional, integration, data, model, retrieval, agent, security, privacy, performance, resilience, accessibility, user acceptance, red-team, control and operational-readiness testing.
- **11 Deploy and Transition:** release decision, cutover, rollback, data migration, production configuration, hypercare, ownership transfer, training, communications, support and evidence handover.
- **12 Operate and Govern Production:** service management, monitoring, evaluations, incidents, drift, cost, capacity, access reviews, control testing, vendor monitoring, evidence, continuity and reporting.
- **13 Improve and Scale:** benefits review, feedback, optimisation, reusable patterns, new use cases, platform scaling, organisational learning, maturity uplift and roadmap refresh.

## Menu depth rule

Primary menus show lifecycle position, not hundreds of article links. Desktop uses a lifecycle panel; mobile uses an accessible stage accordion. Stage-local navigation exposes workstreams and pages.
