# CR-001 — Navigation and Theme Synchronisation

Status: approved by user direction  
Scope: RC1 preview  
Lifecycle impact: none

## Problem

The RC1 combined the shared methodology theme with legacy page chrome. Knowledge Centre exposed a second “Home” concept through its legacy navigation. Deliverables and Tools resolved to the same Resources page. About duplicated personal-profile content rather than explaining the platform.

## Approved change

- Preserve the seven approved primary navigation labels and their order.
- Give Deliverables the distinct canonical route `/deliverables/`.
- Give Tools the distinct canonical route `/tools/`.
- Give Lifecycle the distinct canonical route `/journey/`; keep Enterprise AI Transformation at `/transformation/`.
- Retain one canonical Home route: `/`.
- Point the shared brand to the canonical Home route.
- Rebuild Knowledge Centre and About with the shared platform shell.
- Define About as the platform overview; retain the publisher profile as separate supporting content.
- Restore the Ratheesh Technology Ltd. logo and branded warm-neutral footer across the shared shell.
- Reduce homepage hero height, headline scale and action spacing so search and content discovery appear earlier.
- Restore the original editorial colour system: ink, muted slate, pale blue-grey, teal, navy and restrained gold.
- Keep the compact global header and footer visible while page content scrolls between them.
- Add accessible contextual submenus beneath the six non-Home navigation sections.

## Non-impact

No lifecycle stage, sequence, methodology, assessment, deliverable model, template model, RACI or traceability definition changes.

## Acceptance

- Primary navigation destinations are unique.
- Enterprise AI Transformation explains the methodology; Lifecycle navigates its approved stages.
- Primary destinations use the shared header, footer, typography, colour, spacing and responsive behavior.
- Deliverables describes governed outputs.
- Tools describes interactive capabilities.
- Knowledge Centre contains no competing primary navigation.
- About contains no duplicate homepage or contact experience.
