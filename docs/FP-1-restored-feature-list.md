## Restored operations

- Create and import managed pages.
- Delete pages from publication through an audited soft-delete; retained content and versions remain recoverable.
- Save sanitised, versioned content revisions.
- Store SEO, canonical URL, hero and related-page metadata.
- Move content through draft, review, approval, publication and archive states.
- Restore a historical version as a new draft.
- Upload documents and media to R2 with categories, tags and version labels.
- Apply public, authenticated or restricted visibility.
- Control downloads and watermark policy at delivery time.
- Assign administrator, editor, reviewer and member access roles.
- Generate time-limited password reset links and revoke active sessions after password changes.
- Review 30-day page activity.
- Validate/rebuild the searchable record inventory.
- Generate governed editorial briefs explicitly marked for human review.
- Record administrative actions in an audit log.

No production data or public portal page was overwritten.
