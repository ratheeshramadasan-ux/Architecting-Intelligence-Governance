SECURITY & PRIVACY

PII protection and non-enumeration are platform controls

PII pipeline

  1. Detect & classify PII in text/documents
  2. Apply policy: allow, redact, tokenize or review
  3. Store token ↔ original value in encrypted client-controlled vault
  4. Bind mapping to trace/session with short TTL
  5. Send minimized/masked data to AI
  6. Validate model response
  7. Deterministically rehydrate authorized placeholders
  8. DLP/output validation before customer response

Non-enumeration

Account does not exist
Account belongs to another customer
Both externally return
RESOURCE_NOT_ACCESSIBLE

No confirmation of account existence, ownership, balance, account type or customer identity is exposed to the LLM or customer.

High-risk actions

A $30,000 credit-limit request above the demo auto-approval threshold enters a durable PENDING_APPROVAL workflow. The conversational agent cannot approve or execute it by itself.
